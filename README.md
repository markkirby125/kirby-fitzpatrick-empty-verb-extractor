## Overview

The **Empty Verb Extractor** targets "zombie nouns" (nominalizations ending in `-tion`, `-ment`, `-ance`) and paired weak verbs (`perform the implementation of` $\to$ `implement`), converting bureaucratic prose into clean, muscular actions across documentation and code reviews.

## Core Patterns

- **Zombie Noun Hunter**: Identify nouns ending in `-tion` that hide active verbs.
- **Empty Verb Demolition**: Replace *perform*, *conduct*, and *execute* with the underlying action.
- **Active Predicate Restoration**: Connect actors directly to their transformations.
